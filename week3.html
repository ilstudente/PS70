Fabrication

Overview

This project is a motorised planetary gear system cut from wood on the laser cutter. The outer ring gear is glued to a plywood base plate, and the motor shaft connector is glued to the middle sun gear, keeping the assembly fixed so only the planet gears spin. The motor housing is based on Kassia's box design. Power comes from the ESP32's 5V pin, with the motor wired directly to it.

Human-LLM Interface for Math

A portable blackboard drawing/writing mechanism that can fit to any blackboard and is linked to an LLM, with integrated loudspeaker capabilities.

Motivation: Current computer-based LLM interfaces are not conducive for mathematical work. Studies show that working on a blackboard makes mathematical thinking easier and better. An audio and visual interface allows for a lecture-style interaction, and potentially enables "discussions" with the LLM similar to conversations with a real teacher.

Key Features:

  • Portable mechanism that attaches to any existing blackboard
  • Real-time handwriting and drawing recognition
  • LLM integration for mathematical problem-solving and explanations
  • Audio output via loudspeaker for verbal explanations
  • Supports interactive, dialogue-based learning

Why this matters: Combining the tactile, spatial benefits of blackboard work with the computational power of LLMs could create a more natural and effective interface for mathematical learning and problem-solving.
